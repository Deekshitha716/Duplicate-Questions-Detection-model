# Duplicate-Questions-Detection-model
This project focuses on detecting duplicate or highly similar questions using Natural Language Processing (NLP) techniques. The system processes and cleans text data, removes unnecessary characters and stopwords, and then uses Sentence Transformers and similarity metrics to compare questions and identify duplicates.

The model calculates semantic similarity between sentences rather than relying only on exact word matching. This helps detect questions that have the same meaning but different wording, making the system more accurate for real-world datasets.

The project also demonstrates data preprocessing, database connectivity, text normalization, and similarity analysis using Python libraries such as Pandas, NLTK, SentenceTransformers, and SQLAlchemy. It can be useful for applications like FAQ systems, support ticket management, and knowledge base optimization by reducing redundant queries.
